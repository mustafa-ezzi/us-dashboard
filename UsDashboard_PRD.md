## 1. Product Overview

Us Dashboard is a private, invite-only web application built exclusively for two people in a relationship. It serves as a shared living record of their relationship — tracking stats, memories, moods, responsibilities, and inside moments — all in a clean, data-driven interface that respects both partners' personalities.

This is not a typical "cute couple app." It is a practically designed tool that Ummehani — a mature, straight-forward, SEO content professional — will actually want to open daily. No cringe. No over-the-top romance. Just a well-designed space for the two of you.

### 1.1 Vision Statement

> *"A relationship has data. Let's make it visible."*

Most couple apps are either childish, purely romantic, or filled with pointless features. Us Dashboard is different. It combines the practicality of a personal productivity tool with the warmth of a relationship journal — giving both partners a shared, honest view of their relationship.

### 1.2 Target Users

- **Ummehani** — Primary user. Mature, practical, in the media/SEO field. Values data, clarity, and honesty over fluff.
- **Her boyfriend** — Secondary user. Wants to show effort and thoughtfulness through something genuinely useful.

## 2. Goals & Success Metrics

### 2.1 Product Goals

- Give the relationship a shared, private digital home.
- Make daily interactions meaningful through lightweight logging.
- Replace memory gaps with a living timeline of shared experiences.
- Add a layer of fun and accountability with gamified couple stats.
- Be genuinely useful — not just a birthday gimmick.

### 2.2 Success Metrics

- Both partners open the app at least 3x per week after launch.
- At least 20 memories logged within the first month.
- Mood check-in streak of 7+ days achieved.
- Ummehani does not say "this is useless" within the first 48 hours.

## 3. Feature Modules

The app is organized into **7 core modules**. Each module is designed to be independently useful and collectively meaningful.

---

### MODULE 01 — Relationship Stats Dashboard

The home screen. A clean, at-a-glance summary of the relationship in numbers and visuals.

| Feature | Description | Priority | Phase |
|---|---|---|---|
| Days Together | Auto-calculated counter from relationship start date, displayed prominently. | High | Phase 1 |
| Apology Scoreboard | Tracks who last apologized and total apology count per person. | High | Phase 1 |
| Immaturity Counter | A fun tally of "immature moments" — logged by Ummehani for her boyfriend. | High | Phase 1 |
| Compliment Streak | Counts consecutive days where at least one compliment was exchanged. | Medium | Phase 2 |
| Last Kind Act | Shows the most recently logged kind thing either partner did. | Medium | Phase 2 |
| Relationship Score | A weekly auto-computed score based on mood logs, kind acts, and check-ins. | Low | Phase 3 |

---

A private, beautiful archive of your shared moments. Like a digital scrapbook — but organized and searchable.

| Feature | Description | Priority | Phase |
|---|---|---|---|

| Memory Timeline | Chronological scrollable feed of all memories with visual thumbnails. | High | Phase 1 |
| Memory Search | Search memories by keyword, date range, or tag. | Medium | Phase 2 |

## 4. Design & UX Guidelines

### 4.1 Design Principles

- **Clean over Cute** — Every screen should feel like a product, not a greeting card.
- **Data First** — Visualize data wherever possible. Charts, counters, and stats over paragraphs.
- **Mobile First** — Optimized for phone use. Both partners will access it on the go.
- **Minimal Friction** — Core actions (log mood, add memory, check stats) should take under 30 seconds.
- **Private by Default** — No social sharing. No public profiles. Completely closed system.

### 4.2 Visual Identity

| Element | Decision |
|---|---|
| Primary Color | Deep rose / magenta — `#E91E8C`. Headers, CTAs, accents. |
| Secondary Color | Soft blush pink — `#FCE4EC`. Backgrounds, tags, highlights. |
| Text Color | Near-black — `#2D2D2D`. Clean and readable. |
| Font | Inter or DM Sans — modern, clean, professional. |
| Icons | Lucide or Phosphor icon set — minimal and sharp. |
| Charts | Recharts or Chart.js with custom color palette. |

### 4.3 Key Screens

- **Home Dashboard** — Stats overview with cards for each module.
- **Memory Jar** — Timeline feed with filters and add button.
- **Mood Graph** — Weekly chart with both partners' moods overlaid.
- **Contract Board** — Active rules list with violation log.
- **Responsibility Board** — Kanban-style task list with scoreboard.
- **Joke Dictionary** — Searchable card grid.

## 5. Technical Architecture

### 5.1 Recommended Stack

| Layer | Technology | Reason |
|---|---|---|
| Frontend | React + Next.js (App Router) | Fast, SEO-ready, easy to deploy. |
| Styling | Tailwind CSS + shadcn/ui | Clean, consistent, fast to build. |
| Backend | Next.js API routes | Keeps everything in one repo. |
| Database | Supabase (PostgreSQL) | Free tier sufficient for 2 users. |
| Auth | Supabase Auth | Simple email/password or magic link. |
| Storage | Supabase Storage | For memory photos and voice notes. |
| Charts | Recharts | Lightweight and React-native. |
| Deployment | Vercel | Free tier, instant deploys, custom domain. |
| Notifications | Web Push API | Native browser push notifications. |

### 5.2 Data Privacy

- No third-party analytics or tracking.
- All data stored in a private Supabase project.
- Row-level security ensures each user only sees their own data.
- Option to export all data as JSON or CSV at any time.
- Option to permanently delete all data with one click.

## 7. Out of Scope

The following are explicitly **not** part of this product:

- No social sharing, public profiles, or external integrations.
- No AI chatbot or assistant features (this is not a therapy app).
- No gamification with external rewards — internal fun only.
- No compatibility tests, love calculators, or zodiac features.
- No subscription paywalls — this is a private personal tool.
